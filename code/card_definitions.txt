Your project must be implemented in C
Your project must contain at least:

Two header files (.h files).
Three C source files (.c files).

A suggested organization is:
main.c

Main menu.
Program initialization.
Main game loop.
Calls to player setup, deck management, battle, and exit functions.

card.h

MCard structure definition.
Card-related function declarations.

player.h

Player structure definition.
Player-related function declarations.

card.c

Card creation and display functions.
Card validation.
Type-bonus calculations.

player.c

Player initialization.
Deck management.
Hand management.
Card selection.

battle.c

Stack implementation for decks.
Queue implementation for cards.
Battle resolution.
Life Point scale.
Winner determination. MAKE THE CODE AS SIMPLE AS POSSIBLE. THIS VERSION OF INSCRYPTION ONLY INVOLVES THE CARDS LISTED. WE DO NOT INCLUDE BONES IN THIS VERSION.
